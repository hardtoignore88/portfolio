# Steven Gladman – Portfolio

Static, responsive portfolio homepage (plain HTML + CSS, no build step).

Open `index.html` in a browser, or serve the folder (e.g. `npx serve .`).

## Adding your images

The page shows coloured placeholders until these files exist:

| File | Used for |
| --- | --- |
| `images/steven.jpg` | Hero profile photo (square, shown in grayscale) |
| `images/uk-debt-expert.jpg` | "Digital Campaigns & Content" card |
| `images/salty-dog.jpg` | "Branding & Website Design" card |
| `images/optical-express.jpg` | "A little bit of everything…" card |
| `images/ux-case-studies.jpg` | UX Design Case Studies panel |
| `cv/steven-gladman-cv.pdf` | "Download CV" buttons |

Client logos are text placeholders in `index.html` — swap each `<span class="logo">` for an
`<img src="images/logos/…" alt="…">`.

Also update the
"Find out more" links once those pages exist.
